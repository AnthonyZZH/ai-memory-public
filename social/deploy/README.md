## 执行次序（待补全，禁止直接执行）

1. 等基础环境完成、主人审核与开始指令；只读确认 Windows、可用磁盘、Node >=24.9、Python/Git 版本、权限和既有目录；不读取或输出 XQ_DEEPSEEK_API_KEY。
2. 在本地固定官方 NTQQ、NapCat Shell、微信安装包及 DSH npm 版本，记录发行来源、版本、资产名和 SHA256，审核并锁定依赖；对应 QQ 版本及各安装参数先验证。不得使用 latest、一键整合包或未经审核的镜像。安装前核验散列和签名，记录 VERSIONS.md 与 SETUP_LOG.md。
3. 建立 `C:\xiaoqian\setup`、`app`、`data`、`logs` 等新目录，若冲突停止而不是覆盖。只传输已验证构建、已审社交人格及 public 导出，绝不传主库/私密库/主人数据。发布 public 严格经 publish-public.py 校验；只读网关仅暴露 search/read，并须实际验证权限边界。
4. 先完成 NapCat 的 rkey 源码禁用补丁并验证所选二进制实际行为；在服务器以备份和回滚方案新增独立出站阻断规则与 hosts 条目，拦截 ss.xingzhige.com、secret-service.bietiaop.com 和 106.55.0.102。域名解析 IP 会变化，需验证 IPv4/IPv6、DNS 与直连、规则有效性以及实际 NapCat 出站，不能以 hosts 或单次连接失败推断全面拦截。第三方必要连接和遥测须审核；未确认则停止上线。拒绝改入站规则。
5. 安装固定 NTQQ 和 NapCat Shell；主人在交互桌面扫码。针对所选版本生成 schema 正确配置：WebUI 和 OneBot 独立 32 字节以上随机 token，仅 IPv4 127.0.0.1；拒绝公网或 IPv6 通配监听。所有其他连接关闭，音乐签名为空、插件市场关闭、自动更新路径经实际版本验证关闭。token 不打印，不入版本库。
6. 安装固定 DSH；独立 DSH_HOME 和 qq-social profile；安装已打补丁的 dsh-napcat，不重建覆盖 lib。构造最小 preset 并对最终合成工具注册表逐项核验：当前会话工具、人格、时间、压缩和只读公开库；禁止文件、shell、通用发送、浏览、任务、插件市场和 skill 等。空白名单默认拒绝，建立主人批准的好友及群名单。启动设置 DSH_TELEMETRY_DISABLED=1，禁 session telemetry/反馈，Web 仅本机 --no-open。读取机器级 XQ_DEEPSEEK_API_KEY 的位置留给启动进程，不显示其值。
7. 从腾讯官方安装 Windows 微信；主人扫码。用已验证微信构建部署到 `C:\xiaoqian\app\wechat`，全新数据放 `C:\xiaoqian\data\wechat`；同一人格快照写入应用认可的 persona 格式。设置 api_key_env 为 XQ_DEEPSEEK_API_KEY，不保存密钥。微信可信聊天名单由主人允许的好友和群建立；需要交互桌面及单 worker。当前补丁的 DATA 固定在 app/data，必须先修改补丁并重跑契约，不能假设 data 参数有效。
8. 每日计划任务：经确认的 QQ/微信媒体缓存超过 7 天清理；日志按日切分且保留 14 天；原始聊天只有证明相应内容已提取、封存且超过 30 天时才清理。未能证明提取时保留并报告，不能按文件时间盲删仍在使用的历史。抖音暂不部署，未来处理链须在成功或失败的 finally 清除下载，不能声称计划任务等同即时删除。C: 可用空间小于 5 GiB 写本地告警文件。清理脚本要限制明确路径、拒绝 junction/符号链接、默认 dry run、记录数量和错误；正式启用须测试过期/边界/锁定/未提取情况及重复运行。
9. 验收：实际监听地址与错误 token 拒绝、rkey 三目标阻断、无危险工具、名单外不触发、社交人格哈希相同、跨聊天隔离、主动频率及重启持久化、无正文日志、无真实密钥输出；远程桌面断开行为单独核查。真实 DeepSeek 调用需主人先自行设置密钥。V3.3 红队和真实收发验收通过前不进群。
