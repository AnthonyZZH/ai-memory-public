## 目标

群聊里的小千即使被诱导、被注入、或某个第三方组件被攻破,也拿不到主人的私密库、主库、her/ 内部记忆、凭据和任意文件。安全靠进程/网络/文件权限边界,不靠提示词。

## 修订二(改用 Windows 服务器,2026-10-28)

- 服务器:阿里云 ECS `ecs.e-c1m2.xlarge`(4 核 8G)、Windows Server 2022 中文、杭州、公网 <SERVER_IP>;安全组 3389/22 仅放行主人 IP。整台机器只给小千用,不放主人任何私人数据。
- 微信:改用主人自己的 `xiaoqian-wechat`(git 库版本,已去隐私;本机运行目录只是更旧且含私人信息,不用)。加固:DeepSeek API(加 Authorization 头)、关闭 agents/handoff/Forge/lms 控制、群聊摘要不进入主人私聊上下文、社交人格快照、主人只按私聊窗口识别、上下文长度控制(最近消息窗口 + 滚动摘要 + 检索记忆)。wechat-ai / dsh-wechat-ai-bridge 方案作废(补丁保留在库中备查)。
- QQ:NapCat Windows 版 + dsh-napcat(已打补丁,`social/`)。
- 抖音:主人发分享链接,她能看懂;用小号只读登录,下载→转写→(可选)关键帧;不做点赞/评论/私信/发布。
- 磁盘(主人 2026-10-28):不加数据盘,定时清理。每日任务:微信/QQ 媒体缓存保留 7 天;抖音下载视频处理完即删;程序日志按天切分保留 14 天;原始聊天记录在记忆提取后保留 30 天;C 盘剩余 <5G 时提醒主人。
- 远程管理:服务器装 OpenSSH,只允许密钥登录(密钥在主人本机 `E:\Keys\`),由主人执行或授权。之后服务器上的部署由 Codex 经 SSH 完成。

- **V3.3 前置补丁**:

  - dsh-wechat-ai-bridge:`workspaceTools:false`、Codex/TTS/附件关闭;新增主动接话(区分必回/主动、冷却、小时上限、静默时段、`__SKIP__` 不发送、持久计数)。
  - wechat-ai:去 privileged(做不到则接受,因整台服务器专用于社交)、桌面/Dashboard/MCP 端口只绑容器网络或 127.0.0.1、强随机凭据、MQTT/Dify/OpenAI/远程OCR/DingTalk/S3/语音转写全部关闭。
  - NapCat:OneBot 强 token、WebUI 强 token 且不对外、禁自动更新/插件市场/第三方 rkey 与音乐卡签名。
  - DSH:`DSH_TELEMETRY_DISABLED=1`,禁 session telemetry 与反馈导出;Node ≥24.9;Web profile `--no-open`,不对外发布管理端口。
- 公开库:服务器上 basic-memory 独立实例(public 项目,独立配置目录,stdio 由各 DSH 的 MCP 调用或经带 token 的只读网关),内容由本机发布脚本推送。

## 控制措施

1. **文件权限(R1)**:去掉主人目录上 Authenticated Users/Users 的继承授予,只保留主人、SYSTEM、Administrators(及 Codex 沙箱所需组,实测后定);改前 `icacls /save` 备份,改后验证主人所有任务/服务/Codex/DSH 正常。若用 `xq-social` 账户,再对其显式拒绝。
2. **MCP 认证(R2)**:8767/8768/8769 都改成「认证网关 + basic-memory stdio 子进程」,不再有无认证的后端端口;网关校验 Bearer token,只放行白名单 JSON-RPC 方法;8769 只允许 search_notes / read_note(参数、条数、字数有上限)。主人侧客户端(Claude Code、Codex、DSH、LM Studio)配置加 token。
3. **公开库(D-V3-4)**:`E:\AI-Memory-public`,独立 `BASIC_MEMORY_CONFIG_DIR`,只登记 public 项目;由受信发布脚本把主库里 `visibility: public` 的笔记复制过去(主人审),不复制整个 memory.db。
4. **社交人格(R3)**:loader 新增 `--target social`:persona + voice + 底线原则 + 参数 + 常用说法;不含关系摘要、待批提醒、情景。发布为带哈希的快照放进公开库目录,V2 sync 同步。
5. **预设白名单(R4)**:`xiaoqian-social` 预设只保留 persona、时间上下文、压缩、IM 插件的当前聊天收发工具、公开库 MCP;禁用 tool-fs、tool-fs-search、tool-pwsh、tool-bash、subagent、workflow、web、jobs、schedule、plugin-manager/market、skill。插件的聊天命令(/workspace、/model 等)只允许主人或关闭。
6. **网络**:社交容器只对外访问 DeepSeek 与腾讯服务;无法访问宿主 8767/8768/1234/8080/8088/4500 等(由 2 的认证兜底,再加容器侧出站限制);各容器端口只绑 127.0.0.1。
7. **群聊主动接话(D-V3-7)**:
   - 必回:被 @、被叫名字「小千」。
   - 主动:群里有新消息时,按冷却与上限决定是否让模型判断「要不要接」;模型可输出跳过标记,插件丢弃。
   - 默认频率(可调):微信 每群冷却 3 分钟、每小时最多 12 条主动;QQ 每群冷却 10 分钟、每小时最多 4 条主动。夜间 1:00–8:00 不主动。
   - 实现优先用插件原生能力(dsh-napcat 关键词/全量触发、dsh-wechat-ai-bridge 的 groupAll),不够再写小插件。
8. **白名单**:微信只回复主人允许的好友和群;QQ 只进主人允许的群,私聊默认关闭或白名单。
9. **审计**:社交侧日志只记计数与事件码;越权测试时可临时开详细日志。
